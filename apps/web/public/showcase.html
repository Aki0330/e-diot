2026.11 · 内部汇报

01 / 核心定位

先把账记对，
再让记录有用。

目标用户：想记账但坚持不下去的年轻人。产品先降低「记」的成本，再用反馈解决「坚持」，最后才谈理解与陪伴。

ENTRY · 入口

记账

一句话完成金额、分类、备注、时间结构化；漏账、错账可手动补录与修改。

VALUE · 价值

预算与洞察

记账同时校验预算；总览回答「钱花到哪了」，跨阈值才提醒，不打扰。

MOAT · 长期

记忆与陪伴

记住偏好与边界；在你允许的时间出现一次，反馈可修正记忆。

不是泛聊天助手，也不是企业财务软件；不做无依据的健康评分。记账是入口，理解与陪伴是长期方向。

02 / 运作流程

一次记账，产生四次价值。

01 INPUT
说一句

「午餐花了 50」或手动补录。

02 PARSE
结构化

金额、分类、备注、时间写入账本。

03 CHECK
预算校验

分类/总预算即时判断，跨阈值提醒。

04 LEARN
沉淀

形成分类统计、行为规律与长期记忆。

05 CARE
恰当回应

到点出现一次；反馈修正下一次。

用户生命周期
首次记账→7 天形成习惯→30 天积累洞察→长期个性化
闭环：用户反馈（有帮助 / 不准确 / 暂时别提醒）→ 修正记忆与策略 → 下一次更少打扰、更准确。

04 / 规划目标

三步，把「记完有用」
做成壁垒。

近期 · 0–2 个月

洞察 v1 + 建议模板

每条观察附依据与时间范围；周报呈现变化；消费建议先跑模板。

成功标准：每条结论可核对；建议有帮助率可测。
中期 · 2–6 个月

知识库 + 多维记录

Milvus 混合检索接入；从消费扩展到饮食、作息、目标；通知渠道。

成功标准：回答有出处；不依赖单一消费数据。
长期 · 6–12 个月

数字人与情绪价值

人格 × 记忆 × 形象/声音；情绪识别与克制的主动建议。

成功标准：人格一致、可关闭、可解释。
明确不做：泛陪聊、健康评分、无依据的结论。先把「记账 → 洞察」做可信，再扩展陪伴。

05 / 规划细化 · 知识库与数字人

让回答有出处，
让陪伴有形象。

KNOWLEDGE BASE · P4b

知识库：从「查账」到「给方法」

  1. 语料：理财常识、消费方法、用户自建笔记与目标；不收录医疗诊断内容
  2. 索引：BGE-M3 dense + sparse，Milvus 0.7 / 0.3 混合检索
  3. 精排：Reranker 取 Top-N，片段截断 200 字并保留来源
  4. 接入：Agent tool + MCP knowledge_search，回答附「来源 + 时间」
建议节奏：2 周入库/检索 → 2 周离线评测 → 2 周接入与引用展示。
验收：Top-5 命中率、引用准确率、无出处回答占比。
DIGITAL HUMAN · 长期

数字人：同一人格的四种载体

  1. 表达：人格 prompt + 策略层（决定是否开口）
  2. 记忆：偏好 / 目标 / 边界，决定「能说什么」
  3. 形象：2D avatar + 倾听 / 思考 / 说话状态
  4. 声音：TTS 音色（先预设，后定制）
路径：先做可见的人格（形象 + 状态），再评估声音定制；不做换皮聊天。
验收：人格一致性、主动消息关闭率、用户授权率。
知识库解决「说得对」，数字人解决「愿意听」；两者都建立在可删除的记忆与用户授权上。

06 / 规划细化 · 情绪价值与消费建议

不只回答「花了多少」，
还要回答「然后呢」。

L1 · 接住情绪

先共情，不诊断

识别「累 / 焦虑 / 开心」等表达，先回应感受；不贴心理标签，不说教。

L2 · 给出选项

2–3 个可执行建议

结合预算与记录，给金额、频率与替代方案，并标注依据；不推荐具体金融产品。

L3 · 轻量提醒

在允许的时间出现

到点一次、可暂停；不制造焦虑，不用「你又超支了」这类指责式表达。

机制

情绪/场景标签 → 记忆边界（不喜欢被问什么）→ 建议模板 → 反馈（有帮助 / 不准确 / 别提醒）。

边界

不做医疗/心理诊断，不推荐具体理财/信贷产品，不评价身材；主动建议可随时关闭。

指标

建议有帮助率、主动消息关闭率、D30 留存、预算达成率。

分阶段：先做消费建议模板与反馈闭环，再接情绪识别；所有建议必须能回到记录。

07 / 差异化

为什么是 E-diot。

01 · 成本

最低的记账成本

自然语言 + 手动补录双通道，把一笔账从 8 步降到一句话；这是持续使用的前提。

02 · 闭环

记录会反过来产生价值

预算校验、分类统计、行为洞察、长期记忆相互咬合，而不是记完就躺在列表里。

03 · 信任

可控、克制、开放

记忆可查可改可删；到点一次、随时暂停；MCP 开放，不被单一助手绑定。

传统记账 App 只记录；通用 AI 没有账本；银行账单没有预算与建议。E-diot 的差异在「记账 → 理解 → 克制陪伴」的闭环。

壁垒不在模型本身，而在持续积累的个人数据、可控的记忆与用户信任。
